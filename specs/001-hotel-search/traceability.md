## Findings

- **EC10 / FR-017 gap closed.** The message was covered by unit tests, but "the search form stays usable" was verified only by hand (T039m, T039n). `unavailable.spec.ts` starts a second production web server on port 3101 with `API_BASE_URL` pointing at a closed port. Seen failing: with the `unavailable` case in `ResultsView.tsx` temporarily changed to throw (the error boundary then replaces the page), the test failed on the missing message; it passes with the real code.
- **US1-AS4 has no end-to-end test.** The backend test covers it (capacity below, equal to and above the guest count). The plan's coverage map claimed a Playwright check; that cell is corrected in plan.md.
